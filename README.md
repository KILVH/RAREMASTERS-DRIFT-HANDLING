# RAREMASTERS DRIFT — HANDLING

Новая отдельная версия игры, 7 октября 2026. Старые репозитории AUDIO-REPLAY, MOBILE и BETA не изменены.

- Инерционная модель дрифта на основе OLD GAME, с контролируемым возвратом зацепа и рулением, зависящим от скорости.
- 17 разных автомобилей; шесть категорий технического тюнинга; индивидуальная резина и детали в сохранении каждой машины.
- Пять легальных трасс, включая Карьер Бубновка с ICE_STUDDED; тренировка и соревнование, девять вариантов направления.
- Судейство LINE 40 + ANGLE 40 + STYLE 20 и серьёзные ошибки из старой версии.
- NPC используют сохранённые заезды, стартуют с интервалом, возвращаются на старт. Парные лидеры воспроизводят запись с первого прохода.
- Фиксированные классы полиции, без привязки максималки патруля к текущей скорости игрока.
- Сохранены музыка и автозвук, Dolbogram, экономика, персонажи, город и мобильные кнопки. Тормоз расположен слева от газа в правом блоке.

## Локальный запуск

Сборка и установка зависимостей не нужны. В этой папке выполните `python -m http.server 8000` и откройте `http://localhost:8000/`.

При установленном Node.js и npm: `npm test`. Это 16 автономных наборов проверок без скачивания пакетов. Можно также запускать каждый `node qa-tests/<имя>.cjs` отдельно.

## Записи и сохранения

Игровые данные локальны в браузере. Новая версия копирует прежний прогресс и читает старые повторы, не перезаписывая старое сохранение. Это работает в том же браузере и на том же origin, например при переходе между проектами `kilvh.github.io`. Данные с localhost или временной ссылки автоматически на GitHub Pages не переносятся.

Для NPC сохраняются до шести завершённых безопасных заездов на трассу/направление. При отсутствии записей обычные NPC используют технический AI. Для парных лидеров поставляются девять подготовленных траекторий; это зафиксированные прогоны контроллера, а не записи человека. Лучшие валидные записи игрока имеют приоритет, персональное назначение хранится в `characterRuns`.

## Проверки и ограничения

Текущие результаты перечислены в `verification/release-tests.json`. Другие ранее существовавшие отчёты относятся к предыдущим релизам. Автоматические проверки физики, реальных масок, судейства, replay, очереди, тюнинга, сохранений и аудио дополнены проверкой интерфейса в Chromium 844×390. Реальный телефон и его FPS этой проверкой не заменяются.
